# Vani Pri - Portfolio Website

A personal portfolio website built with HTML and CSS, showcasing my skills, projects, and contact information.

## 🔗 Live Preview

> Deploy via GitHub Pages to get a live link.

## 📌 Features

- Responsive design (mobile-friendly)
- Sticky navigation bar
- Hero section with profile photo
- About Me section
- Skills showcase
- Projects section
- Contact links (Email, LinkedIn, GitHub)

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome Icons

## 📁 Project Structure

```
portfolio/
├── index.html

```

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/gvanipri-ship-it/Portfolio.git
   ```
2. Open `index.html` in your browser.
